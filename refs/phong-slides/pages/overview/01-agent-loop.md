# Agent làm gì?

**Đọc tài liệu → lập kế hoạch → dùng công cụ → nhận phản hồi**

- Ứng dụng: tìm thông tin, viết báo cáo, tự động hóa tác vụ.
- Khác biệt quan trọng: agent có thể **thực hiện hành động**.
- Ví dụ xuyên suốt: đọc báo cáo và gửi cho đúng người.
